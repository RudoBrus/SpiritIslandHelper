# Spirit Island Companion

A static, mobile-friendly companion website built with React, TypeScript, Vite, and Tailwind CSS.

## Prerequisites

- Node.js 20.19+ or 22.12+
- npm
- Git

## Installation

```sh
npm ci
```

## Development

Start the local development server:

```sh
npm run dev
```

Open the local URL printed by Vite in your browser.

## Tests

Run the unit tests once:

```sh
npm test
```

Type-check the test files:

```sh
npm run test:typecheck
```

## Linting

```sh
npm run lint
```

## Production build

```sh
npm run build
```

The static production files are written to `dist/`. To serve that build locally:

```sh
npm run preview
```
